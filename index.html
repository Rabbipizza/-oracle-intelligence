Évaluation scientifique

Le moteur est maintenant figé pour l’évaluation. La validation doit être menée en deux blocs séparés : prospective walk-forward à partir des snapshots réellement produits, et backtest historique reconstruit avec leak gate strict. Les deux résultats ne doivent jamais être mélangés.

TestObjectif
Leak gateVérifier qu’aucune information postérieure à la date du signal n’entre dans la sélection.
QQQ / SPYMesurer le rendement excédentaire par rapport à une alternative passive.
20 / 60 / 120 / 252 joursMesurer la persistance du signal à plusieurs horizons.
Hit ratePart des signaux qui battent le benchmark à horizon défini.
MAE / MFERisque subi avant succès et potentiel capturé après signal.
False positivesTaux de tendances/sociétés prometteuses qui ne produisent aucune surperformance exploitable.
CalibrationVérifier si les niveaux de conviction correspondent réellement aux résultats futurs.
Entry modesComparer EARLY vs CONFIRMATION vs MOMENTUM vs PULLBACK.
Leader gapTester si CLOSING prédit réellement une meilleure performance future.
Trend accelerationTester si l’accélération mesurée précède une surperformance et non l’inverse.

Aucun résultat d’évaluation n’est affiché tant qu’un horizon suffisant n’est pas écoulé ou qu’un backtest historique propre n’a pas passé le leak gate.

Règles du moteur

Trend → persistance + accélération + qualité/diversité des preuves. Fit → capture économique + croissance + commandes + marges + moat + bilan. Leader gap → CLOSING/STABLE/WIDENING. Entry → accélération fondamentale vs accélération du prix vs expectation gap. Expected Return → bear/base/bull. Benchmark → QQQ/SPY ou benchmark sectoriel pertinent. Allocation → uniquement si l’asymétrie est démontrée.
